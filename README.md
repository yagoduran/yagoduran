## Sobre mí

Soy estudiante de **Desarrollo de Aplicaciones Multiplataforma (DAM)** y estoy construyendo proyectos reales para mejorar como desarrollador. Me interesa especialmente el desarrollo **Android**, el **backend**, las **bases de datos**, la **automatización** y los **sistemas**.

Me gusta trabajar con una base técnica clara: código mantenible, interfaces cuidadas, integración con datos y soluciones que puedan usarse en contextos reales.
